# Short-form feature tutorial video series

Full plan: [what-if-we-require-smooth-lovelace.md](../../.claude/plans/what-if-we-require-smooth-lovelace.md)
(video series planning, approved 2026-08-03).

Goal: unstick existing landlords, agents, and tenants who have the app but
don't know how to use it, one short (15 to 60s) screen-recording-plus-voiceover
video per feature, however small. Secondary benefit: same footage doubles as
public discovery content later.

37 scripts across 5 batches, in shooting order:

1. [Batch 1: core loop](./2026-08-03-batch-1-core-loop-scripts.md) — sign up,
   add a property, add a tenant, invoice, record a payment, tenant pays,
   receipts, renew a lease. **Shoot this batch first as the pilot.**
2. [Batch 2: setup and onboarding](./2026-08-03-batch-2-setup-scripts.md) —
   KYC, bank account, wallet/payout, tenancy agreement, guarantor, invite an
   agent, maintenance requests (both sides).
3. [Batch 3: engagement and retention](./2026-08-03-batch-3-engagement-scripts.md)
   — chat, AI assistant, notifications, reports, marketplace (both sides),
   building community, shared bills, community wallet voting.
4. [Batch 4: edge and setup](./2026-08-03-batch-4-edge-scripts.md) — password
   reset, biometric login, quit notice, guest browsing, referrals,
   subscription/plan, blocking, help center.
5. [Batch 5: coming soon](./2026-08-03-batch-5-coming-soon-scripts.md) —
   WhatsApp AI assistant, WhatsApp onboarding, WhatsApp write actions.
   **Not live in production yet — do not film or publish until the separate
   readiness work in the plan's "Blocker" section is done.**

Before shooting Batch 2's tenancy agreement video, confirm which signing flow
is actually live (native in-app vs. DocuSeal — flagged as ambiguous in the
plan). Before shooting Batches 3 and 4's subscription/plan and
building/community videos, confirm those are meant to be shown publicly
(they're fully built but not in the canonical product spec).
